# Two-Factor Authentication (2FA)

Two-Factor Authentication (2FA) adds an extra layer of security to your account by requiring a second form of verification in addition to your password. This helps protect your account from unauthorized access, even if someone obtains your password.

## Setting Up Two-Factor Authentication

To enable 2FA on your account:

1. Navigate to **Account Settings** from your profile menu
2. Select **Security** from the left sidebar
3. Click on **Two-Factor Authentication**
4. Choose your preferred authentication method:
   - **Authenticator app** (recommended): Use apps like Google Authenticator or Authy
   - **SMS**: Receive verification codes via text message
5. If using an authenticator app:
   - Scan the QR code displayed on screen with your authenticator app, or
   - Manually enter the setup key provided if you cannot scan the QR code
6. Enter the 6-digit verification code from your authenticator app or SMS to confirm setup
7. **Save your backup codes** - these will be displayed once during setup. Store them in a secure location

Your 2FA is now active and will be required each time you log in.

## Important Information

- **Backup codes**: You will receive a set of backup codes during setup. Each code can be used once to access your account if you don't have access to your primary 2FA method. Keep these codes in a safe place.
- **Account recovery**: If you lose access to both your 2FA method and backup codes, you must contact our support team to regain access to your account.
- **2FA is optional**: While 2FA is not required by default, we strongly recommend enabling it to protect your account.
- **Organization enforcement**: Organization administrators can enforce 2FA for all users from the Admin panel, making it mandatory for everyone in your organization.

## Troubleshooting

**I can't scan the QR code**

If you're unable to scan the QR code with your authenticator app, use the manual setup key provided below the QR code instead.

**My verification code isn't working**

- Ensure your device's time is synchronized correctly, as authenticator apps rely on accurate time
- Double-check that you're entering the most recent 6-digit code
- If using SMS, wait for a new code to be sent if the current one has expired

**I lost access to my 2FA device**

Use one of your backup codes to log in, then set up 2FA again with a new device. If you don't have your backup codes, contact support for assistance.
